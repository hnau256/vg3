---
title: "vg3"
---

**vg3** turns code into solid 3D models and exports them to STL / STEP / PNG.

A typed Kotlin DSL describes the model, serializes it to a canonical JSON IR, and a small Rust
engine builds the shapes with OpenCASCADE.
