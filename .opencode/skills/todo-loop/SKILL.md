# Todo loop

Разбирает `TODO.MD` в корне проекта по одному пункту за раз. Работает в цикле, пока в файле
остаётся хотя бы один пункт. Источник правды — только `TODO.MD`; порядок пунктов сверху вниз.

## Предусловия

1. Прочитай `AGENTS.md` — правила проекта обязательны для каждого пункта.
2. Убедись, что рабочее дерево чистое (`git status`). Если есть незакоммиченные изменения —
   остановись и сообщи, не смешивай их с работой по TODO.

## Цикл

Повторяй, пока `TODO.MD` не пуст (или не остались только пустые строки):

1. **Читай первый пункт.** Возьми самую верхнюю непустую строку `TODO.MD`. Всё, что ниже
   (в т.ч. вложенные подпункты этой задачи) — контекст текущего пункта.
2. **Выполни пункт полностью.** Реализуй изменение, следуя `AGENTS.md`. Прогони проверки:
   линт/типы/тесты, релевантные изменению. Не оставляй пункт частично сделанным.
3. **Удали выполненный пункт** из `TODO.MD` — вычеркни только его строку(и), остальные
   пункты не трогай. Если после удаления файл пуст, оставь пустой файл (не удаляй сам файл).
4. **Закоммить.** Стиль сообщений — как в репозитории (`git log --oneline`). Один пункт — один
   коммит. Стейджи только относящиеся к пункту файлы (`TODO.MD` + изменения задачи).
5. **Запушь** в тот же remote/ветку, откуда взял (`git push`).
6. **Вернись к шагу 1.**

## Остановка

- `TODO.MD` пуст/отсутствует — задача выполнена, сообщи об этом.
- Пункт невозможно выполнить (блокер, неоднозначность, провал проверок) — **не удаляй** его,
  остановись и явно доложи, что сделано и что мешает. Не деградируй и не пропускай пункт молча.
- Не коммить и не пушить незавершённый пункт.

## Запрещено

- Пропускать пункт, удаляя его без выполнения.
- Коммитить несколько пунктов в один коммит.
- Пушить посторонние изменения, не относящиеся к текущему пункту.
